# Security

Hop talks to the other Mac on the local network. Messages are signed but not encrypted. It does not use an account or a cloud service.

Hop only connects to Bluetooth devices already paired on this Mac. It does not pair new devices.

If you find a security problem, open a private security advisory on this GitHub repository. Please do not file a public issue for a vulnerability.

Include what you did, what you expected, and the macOS version. Do not include Bluetooth addresses, pairing keys, or the contents of `~/Library/Application Support/Hop`.
